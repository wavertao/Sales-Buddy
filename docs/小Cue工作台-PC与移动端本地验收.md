# 小Cue工作台：PC与移动端本地验收

2026-11-15。实现分支：`codex/workbench-responsive`，基于最新develop `96901b5`。Git传输连接超时后，通过GitHub API读取并校验原始提交哈希及树一致性，安全快进任务基线，保留原型和现有用户数据。

## 本地查看

开发服务为 http://127.0.0.1:3001/home ，`npm run dev`启动。浏览器F12后按Ctrl+Shift+M开启设备工具栏，选择390×844或iPhone尺寸；刷新后也可直接进入 `/goals`。

- 视口宽度≤820px：隐藏PC侧栏和工作空间顶栏，显示“对话、线索/商机、小Cue、目标、工具箱”底栏，底栏适配安全区。
- 320、390、430、768px视图均检查横向溢出；切回1440px恢复PC布局。
- 小Cue首页只显示简报和提醒，卡片单列、与内容区等宽，取消最小高度；压缩内边距、段落和页脚间距，呈现横向舒展、纵向紧凑的比例；PC为双列Feed。
- 目标包含待办和日程Tab。返回时保留当前Tab、日期与提醒筛选。其他原有能力仍可从PC应用入口或工具箱访问。

## 已实现

1. 提醒首屏8条，生成及输出校验上限8条；旧5条生成缓存自动补一次新规则生成。有依据不足8条时不凑数，跨日保留原有进行中和用户反馈。
2. 点赞/点踩互斥可取消；中性灰双√为未完成，已选中双√再次点击取消完成；完成后提供5秒撤销。提醒和CRM任务状态独立。
3. 详情有标题、描述、实际关联实体信息来源、推进建议和统一AI判断提示。实体只从真实可访问来源及明确父级关系投影，不伪造三类来源齐全。
4. 目标待办沿用P1.3b：逾期、今天到期、本周剩余、已完成；必要时显示以后/未排期。统计基于完整授权集合，各组独立分页，每组20条。
5. 清单显示勾选框、优先级、描述、预计完成日期、发起人。发起人缺失为“未记录”，不以执行人冒充。
6. 新建沿用CRM确认创建、防重复和权限校验，执行人固定本人；无右侧校验与提交说明区，失败在表单内显示并保留输入。
7. 文字/语音补录先形成可编辑草稿，再确认创建。真实模型解析已验证，解析请求不创建CRM任务。不支持语音、拒绝权限、识别失败或模型异常时保留文字，并可转手动表单。
8. 用户完成待办后产生版本化状态事件，写入可查看的“今日日报 · 完成记录”；取消完成保留审计，锁定/已发布日报追加更正。同步失败不撤销已完成任务，分钟后台重试，也可手动重试。
9. 日报洞察只对明确关联的本人任务闭环：多任务全部完成后自动闭环，恢复任务后仅撤销系统自动闭环，不改人工关闭状态。任务与洞察关联接口为 `/api/my-tasks/:id/insight-links`。没有既有洞察或关联时只记录日报，不生成虚构洞察；本轮不增加独立洞察编辑器。
10. 日程保留日期切换、开始时间和现有CRM活动记录，移除会前讨论与会晤材料按钮。P11原有独立功能继续保留。
11. 修复回归发现的新会话切换时序：加载完成前禁用发送，防止消息写入上一会话；画像按钮加载时禁用，避免点击无响应。
