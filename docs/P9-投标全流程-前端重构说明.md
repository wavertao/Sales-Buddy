# P9 投标全流程 · 前端重构说明

依据设计稿 `投标全流程.html`（PC 25 屏 + 移动端 6 屏）重写 `apps/web/src/p9/`，替换原单文件 `P9Workspace.tsx`。后端接口与状态机不变。

## 目录

| 文件 | 职责 |
|---|---|
| `P9App.tsx` | 入口：列表 / 商机 / 详情（11 个 Tab）/ 移动端 切换，挂载弹窗与提示 |
| `store.tsx` | 页面状态与动作（完成待办、评论、推进节点 / 轮次、发起投标等），后端接通时同步调用接口 |
| `live.ts` | `/api/bids*` → 视图模型映射；接口不通时整块回落演示数据 |
| `demo.ts` | 设计稿文案与数字（主标 BID-20261010-003） |
| `ui.tsx` | 卡片、胶囊、按钮、章节头、字段、表格、弹窗等通用组件 |
| `shell.tsx` | 左侧栏、详情顶栏 / 节点条 / Tab 行、右侧常驻投标助理 |
| `screens/*.tsx` | 按屏组：list（P9.0）· cockpit（P9.1）· basic（P9.2）· plan（P9.3）· docs（P9.4）· meetings（P9.5 / P9.6）· todos（P9.7）· submit（P9.8–P9.10）· mobile（P9M） |
| `p9.css` | 全部样式（设计稿色板 / 字号），`:where()` 重置主应用的元素级全局样式 |

## 交互要点

- `/p9` 全屏显示设计稿自带的侧栏；侧栏其它模块跳回原工作空间页面。
- 节点条当前阶段可点击 → P9.2.3 推进确认（无遮罩，贴在节点条下方）。
- 计划甘特条可拖动改期 / 拖两端改起止，调用 `reschedule` 接口；编辑态支持改条目名、负责人、参与人、状态、起止、删除行。
- 待办勾选 → 完成弹层（完成情况 + 说明 + 附件）→ 调用 `complete` 接口并进入详情；评论、重新打开同样落库。
- BAFO 报价单按 `/quote-visibility` 做严格权限：无权限只显示「已报价」状态。
- 后端种子原先直接引用前端 `data.ts`，已迁到 `apps/server/src/p9/seed-frontend.ts`，种子内容不变。
