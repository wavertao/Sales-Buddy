# 商机领航员与普通对话

2026-11-16，本地迭代；依赖PR #21工作台基线，未部署云端。

## 交互

- 线索/商机板块右下角悬浮入口打开赢单领航员，移动端避开底部导航。搜索和最近沟通仅列出有权限商机。
- 在商机概览显式新建对话；顶部保留关联商机，列表显示赢单领航员标识。客户和线索不作为新领航员入口。既有历史可继续访问，不迁移用户内容。
- 对话板块“新对话”创建普通对话，不预设客户或商机。
- 普通对话提及商机时，按名称/编号匹配或由模型调用只读查找工具；服务端校验商机类型、权限后输出真实链接。点击仅进入商机概览，用户再新建独立对话。普通会话保持无关联，不写画像、CRM或个人记忆。

## 数据与接口

复用现有会话、消息、运行、事件和日志持久化。新建会话支持kind=general（无scope）或kind=navigator（scope必须为opportunity）。兼容旧调用和历史数据，历史客户/线索对话不显示领航员标识。无范围的消息进入独立普通问答流程。结构化跳转链接在生成及历史读取时重验权限，模型提供的项目链接不作为可信入口。重复提交由前后端运行锁防护。
