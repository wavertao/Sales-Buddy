# 画像与MPT移动界面

实现位置：本地应用商机领航员新对话，390×844及≤820px响应式布局。PC原矩阵保留，新增画像详情。Pencil本期额度已用尽，本轮不修改原型文件；本说明与应用内可操作页面记录交互设计。

## 商机会话

返回/历史 → 商机名称与编号 → 当前M:P/T → 项目画像详情｜MPT画布｜开始/继续评估 → 对话内容 → 输入框 → 五项底部导航。

未评估时说明“尚未完成MPT评估”，不填默认M0/P0/T0。已暂存时显示继续评估。仅有共享阅读权限的成员可查看定位，维护入口按权限限制。

## MPT评估

全屏页：M/P/T与确认进度 → 阶段单列选择 → 当前固定问题 → 已确认/未明确/不涉及 → 实际情况 → 上下题与提交 → 维度核实 → 下一维度 → 明确完成保存。

底部保留暂存，重新进入恢复原输入；未知不被写成未完成，也不强行否定销售申报阶段。保存前说明定位共享、原话私有，S阶段独立。

## MPT画布

顶部关闭 → 当前定位与操作 → T采购阶段 → M×P完整矩阵横向容器 → 图例 → 点选格子的策略。

保留全部36格和当前格高亮，横向手势只作用于矩阵，不拉宽整个页面。

## 项目画像详情

顶部返回、名称、最近更新、MPT画布/导出 → 共享/个人范围图例 → 八个固定模块单列卡片 → 我的更新记录。

共享卡片只展示允许公开的当前值；个人卡片可展开本人原话与来源。编辑或新增在底部表单完成，表单明确“团队共享”或“仅自己”。不出现每轮更新通知，不暴露其他成员的个人信息。
