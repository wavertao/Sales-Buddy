# MPT画布交互说明

更新：2026-11-19，覆盖此前阶段选择与内联简图方案。

1. PC与移动端画布均移除“更新记录”“下载画像MD”。
2. 主区域只展示当前M项目落地成熟度、P订单归属及T独立采购阶段，T位于M/P之后，推进建议之前。未评估时明确待确认，不推断默认定位。
3. “查看阶段定义”打开弹窗，以M/P/T页签列出所有阶段名称与说明，并标识当前阶段。浏览定义不修改项目定位。
4. “查看阶段定位图”打开独立弹窗，矩阵始终标记实际当前位置。点击其他格子只查看该组合的建议；当前标记与浏览选择分别保存。提供全屏/退出全屏，Escape优先退出全屏，再关闭弹窗。
   M、P坐标轴同时显示阶段编号与知识库中的完整阶段名称，普通弹窗与全屏一致；手机允许名称自然换行。
5. 手机主页面直接阅读当前M×P推进建议、风险、资源与下一步；PC保留完整矩阵。保留“修改项目阶段”进入既有评估确认流程。
6. 删除辅助性长提示，不在主页面放浏览选择框、内联简图或完整矩阵展开提示。

普通对话与领航员共用输入区样式。以上为本地运行界面；未修改原有未提交Pencil，未部署云端。
